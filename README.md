# ProjectTracker

## О проекте
ProjectTracker — учебное веб-приложение, разработанное в Яндекс Лицее в рамках курса «Промышленное программирование на Python». Система помогает учителю управлять учебными проектами и этапами, а ученику — фиксировать прогресс выполнения и вести рабочую переписку.

## Цель проекта
- Реализовать ролевую систему «учитель / ученик».
- Дать учителю удобный контроль этапов и дедлайнов.
- Дать ученику простой интерфейс обновления прогресса.
- Организовать внутренние сообщения по проекту.
- Поддержать импорт и экспорт рабочих данных в XLSX.

## Функционал
### Учитель
- Создает и редактирует проекты.
- Создает, редактирует и удаляет этапы проекта.
- Добавляет учеников в проект по email.
- Просматривает аналитику проекта по всем ученикам.
- Выгружает отчет проекта и аналитику в XLSX.
- Ведет переписку с учениками в рамках проекта.

### Ученик
- Просматривает список доступных проектов.
- Открывает этапы и видит дедлайны.
- Обновляет статус этапа (`не начат`, `в процессе`, `выполнен`).
- Добавляет GitHub-ссылку и комментарий по этапу.
- Отправляет сообщения учителю в диалоге проекта.

### Дополнительно
- Непрочитанные сообщения учитываются и показываются в уведомлениях.
- Импорт этапов выполняется из шаблона XLSX со строгой валидацией.

## Технологии
- Python
- Flask
- Flask-Login
- Flask-SQLAlchemy
- Jinja2
- Bootstrap 5
- SQLite (2 базы данных: `main.db`, `service.db`)

## Быстрый запуск
```bash
cd ProjectTracker
python3 -m pip install -r requirements.txt
python3 run.py
```

Приложение будет доступно по адресу: `http://127.0.0.1:5000/`

## REST API (кратко)
Основные группы endpoint-ов:
- `GET /api/projects` — список проектов пользователя.
- `GET /api/projects/<id>/students` — список учеников проекта.
- `GET /api/projects/<id>/stages` — этапы проекта.
- `GET /api/projects/<id>/stats` — статистика по проекту.
- `GET /api/students/<id>/progress` — прогресс ученика.
- `POST /api/progress` — создание или обновление прогресса по этапу.
- `POST /api/messages` — отправка сообщения в проектном диалоге.
